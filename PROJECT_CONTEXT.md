# Project Context

AeroPulse is a small portfolio project for a Full Stack Developer interview.

The goal is to demonstrate:

- Next.js and React
- Tailwind CSS
- FastAPI and Python
- SQL data modelling and queries
- pytest
- Playwright
- Basic production architecture thinking

The project uses simulated airline flight data. It is a focused prototype, not a production airline system.

The learner wants to write and understand the code themselves. Claude should explain, plan, review, and suggest small next steps rather than implementing the entire project automatically.
